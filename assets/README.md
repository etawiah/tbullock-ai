# Assets

Files that are **not** part of the app build (nothing here is deployed).

- `print/` — bar branding and print files: logos (full-size originals), the
  coaster artwork, the guest-menu QR code (EPS/PDF/PNG/SVG) and the 3D-printable
  QR plate (`qr_moon_plate.stl`).
- `reference/` — source material: Tom Bullock's *The Ideal Bartender* (1917)
  text and the signature menu notes.

The app uses `public/purple-moon-logo-128.png`, a small copy of
`print/purple-moon-logo.png`.
